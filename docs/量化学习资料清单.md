# 量化学习资料清单

> 给 Tutdy Smith，2026-10-14。按你的情况排的：通信工程背景 + 多年实盘交易经验，正在学数据分析和量化。
> 你的优势是懂市场、懂风险，这是纯技术背景的人没有的。短板可能是 Python 和统计基础，所以顺序是：先补工具，再学框架，最后啃理论。

## 第一阶段：Python 数据分析（1-2 个月）

目标：能自如地拿数据、洗数据、画图。这是地基，跳不过。

- **《利用 Python 进行数据分析》**（Wes McKinney 著，pandas 作者本人写的）
  - 只看 pandas / numpy / 数据清洗 / 可视化这几章，其他先跳过
  - 中文版很好找
- **练手项目**：用 Kraken 公开 API 拉 BTC 数据，算各种均线、画 K 线 + 均线图
  - 你已经在 quant-lab 里做过一半了，继续深挖就行

## 第二阶段：回测框架（1-2 个月）

目标：完整走通"想法 → 回测 → 评估"流程，亲手实现 3-5 个经典策略。

- **Backtrader**（Python 回测框架，文档全，例子多）
  - 先复刻你的双均线策略，对比和你手写版本的结果是否一致
  - 再试：布林带突破、RSI 均值回归、唐奇安通道
- **vectorbt**（向量化回测，速度极快，适合参数扫描）
  - 你昨天做的 9 组参数扫描，用 vectorbt 几秒钟就能跑完几百组
- **vn.py**（中文开源量化框架，文档中文，社区活跃）
  - 以后想接实盘（A股/期货）时再看，现在不用
- **QuantConnect / Lean**（在线平台，数据源丰富，C#/Python）
  - 适合练手，不用自己搭数据管道

## 第三阶段：策略研究与理论（持续）

目标：理解"为什么这个策略有效"，以及"什么时候会失效"。

### 先看这两本（按顺序）

1. **Ernest Chan《Quantitative Trading》**
   - 从零搭一个量化交易业务的全流程，实操性最强，适合你现在看
   - 有中文版《量化交易》
2. **Ernest Chan《Algorithmic Trading》**
   - 均值回归、动量等经典策略的原理和实现，接着上面那本看

### 再看这两本（进阶，别急）

3. **Marcos López de Prado《Advances in Financial Machine Learning》**
   - 回测过拟合、三重壁垒标注法、组合交叉验证——全是防坑指南
   - 难度高，等你前两本吃透了再碰
4. **Larry Harris《Trading and Exchanges》**
   - 市场微结构：订单簿、滑点、做市商是怎么赚钱的
   - 理解"你的对手盘是谁"，对交易者尤其有用

### 工具书（当字典查）

- **Yves Hilpisch《Python for Finance》**：Python 金融应用手册
- **《统计学习方法》（李航）**：机器学习理论基础，中文经典

## 避坑指南（实话版）

1. **别一上来就学机器学习做策略**：先把经典策略（均线、突破、均值回归）玩明白，ML 是放大器，不是印钞机
2. **回测≠实盘**：你已经亲身体会过参数敏感性了，记住这个感觉
3. **数学够用就行**：通信工程的数学底子足够应付 90% 的量化内容，缺的不是数学，是金融直觉——而你有
4. **代码能力 > 理论深度**：能快速把想法变成回测的人，比背得出公式的人值钱
5. **别买课、别买策略**：这个行业卖铲子的人比挖金子的人多
